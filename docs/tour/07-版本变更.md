## V1（2026-10-15）

**主题**：八字（BaZi）最小可用闭环 —— 确定性排盘 + 中性解读 + 同盘追问。

V1 分 6 个里程碑实现，逐层文档描述的就是这个状态。

### 新增

| 里程碑 | 内容 |
| --- | --- |
| M1 包骨架 | `package.json`（ESM / Node ≥20 / 单包双入口）、TypeScript 构建（tsup）、CLI 入口、SDK 入口、错误码、`config doctor` |
| M2 八字闭环 | `BaziCalculator` 接口 + `Tyme4tsBaziCalculator`、`BaziChart` 类型、`xuan bazi analyze`、21 例排盘回归基线 |
| M3 Provider 与 Prompt | `ProviderFactory` + openai-compatible adapter + mock adapter、`PromptManager`（通俗/进阶）、`SafetyGuard` 初版、真实 LLM 解读跑通 |
| M4 RAG 与追问 | `RagEngine`（关键词检索）、seed 知识库（4 篇）、`xuan rag search`、`ConversationState` + `ConversationStore`、`xuan bazi ask`、`xuan session clear` |
| M5 档案与 Provider 表 | `UserProfile` + `ProfileStore`、`xuan profile view/save/delete`、`xuan provider list`、进阶解读接入 RAG 引用 |
| M6 预发布 | README 更新、smoke 测试补全、`npm pack --dry-run` 审计 |

### 决策

- **[ADR-0002](../adr.md)**：计算与解读分离 —— 排盘交给库，LLM 只解释。
- **[ADR-0003](../adr.md)**：排盘库选 `tyme4ts`，经 `BaziCalculator` 隔离（三实现交叉对拍 21 例验证）。
- **[ADR-0010](../adr.md)**：晚子时日柱默认"次日"（23:00 换日），与主流排盘软件一致。
- **[ADR-0011](../adr.md)**：**V1 不引入 LangChain.js / LangGraph.js**，改自研 `LlmProvider` + 线性 `XuanAgent` 流程（取代 ADR-0005）。

### 已知缺口（未修，见 [05 检查清单](05-测试与Review.md#review-检查清单)）

`content.sections` 恒为空 · SkillRegistry 未实现 · RAG 检索词启发式 · 晚子时无切换入口 · CLI 一处越层调用 · SafetyGuard 词表偏短 · 流年未实现。

### 影响文件

`src/` 全部（约 2600 行）、`tests/`（62 个测试）、`knowledge/seed/`（4 篇）、`docs/` 全部。
