# ADR-0008：本地优先存储 + 隐私默认

- 状态：已采纳（Accepted）
- 日期：2026-10-15

## 背景（Context）

出生日期/时间、出生地、面相/手相图片、用户档案、对话历史都属于敏感个人数据。若默认长期保存或写入日志，会带来隐私与合规风险。

## 决策（Decision）

- 存储本地优先：用户档案用本地 JSON（后续可升级 SQLite/DB），会话状态用本地 checkpoint。
- 默认不持久化敏感数据（临时模式），写入长期档案前必须用户显式确认；用户可查看、更新、删除档案。
- 日志脱敏：不记录完整 API key、完整出生信息、完整图片内容、未脱敏档案；API key 只从 `.env` 读取。
- 图像不用于身份识别，不推断种族/民族/宗教/政治/疾病等敏感属性。

## 后果（Consequences）

- 正面：隐私风险低、默认安全；个人工具形态足够。
- 代价：多用户/SaaS 场景需要升级存储与权限体系；临时模式与档案模式并存增加了状态管理复杂度。
