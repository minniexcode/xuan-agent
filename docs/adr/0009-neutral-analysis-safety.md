# ADR-0009：中性分析安全边界（不吉凶断言 + SafetyGuard）

- 状态：已采纳（Accepted）
- 日期：2026-10-15

## 背景（Context）

五术工具的用户往往要"吉凶/运势/成败"结论，但确定性断言有误导、宿命论与合规风险。玄枢的差异化定位是"克制、可追溯、自我探索"，而非算命结论生成器。

## 决策（Decision）

输出坚持中性、非断言、非宿命论：用"倾向""观察角度""传统语境下可以理解为"等表达，避免"必然""一定""大凶""注定"。当用户索要吉凶时，触发 `SafetyGuard` 降级：承认诉求 → 说明能力边界 → 转为可观察的结构/倾向 → 不给是/否结论。该规则进入系统逻辑与 Prompt，而非仅依赖文档免责声明；输出后处理 `audit_output` 审计断言式/恐吓式内容。

## 后果（Consequences）

- 正面：形成"克制、可追溯"的产品护城河，合规风险低。
- 代价：部分用户可能觉得"回避/不够爽快"；需要维护 SafetyGuard 规则表与测试样例。
