# ADR-0002：计算与解读分离

- 状态：已采纳（Accepted）
- 日期：2026-10-15

## 背景（Context）

LLM 直接排盘错误率极高：干支、十神、节气、日期换算等确定性内容容易被模型"编造"。社区共识是"确定性排盘交给工具，AI 只做解读"（问真等排盘工具的用户普遍采用"排盘工具 → 喂给 AI 解读"的用法）。若让 LLM 负责算数，产品会失去准确性根基。

## 决策（Decision）

排盘、历法换算、干支推导、十神映射、大运流年等确定性计算全部由库（`lunar-typescript` 经 `BaziCalculator`）完成。LLM 只负责解释结构化结果、总结观察角度、引用知识库、回答追问、调整表达风格。排盘失败时返回明确错误，不得让 LLM 编造或补算。

## 后果（Consequences）

- 正面：排盘可复现、可测试、可追溯；LLM 幻觉被隔离在解读层；Prompt 中只注入结构化 `BaziChart` 而非生日字符串。
- 代价：需要维护确定性计算层与排盘样例集；LLM 的价值被收敛为"解读与表达"，需要更强的 Prompt 工程。
